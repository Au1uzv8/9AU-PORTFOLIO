📖 คู่มือการใช้งาน & สรุปบริบทโครงการ (Context Summary)

พิมพ์เขียวสถาปัตยกรรมระบบ สรุปการแก้ไข และแนวทางการบำรุงรักษา

1. บทนำและแนวคิดเริ่มต้นของโครงการ (Origin & Core Vision)

ระบบนี้ถูกออกแบบมาเพื่อรวมศูนย์การบริหารความมั่งคั่งส่วนบุคคล (All-in-One Net Worth) จาก 3 แหล่งสินทรัพย์หลัก:

  • Group-1 (สภาพคล่องเงินบาท): ติดตามเงินสดในมือ, บัญชีเงินฝากธนาคาร (SCB/K-Plus), และกองทุนสำรองฉุกเฉิน
  • Group-2 (หุ้น/ETF สหรัฐฯ Dime!): ตรวจสอบยอด Reconciliation กับแอป Dime! คำนวณต้นทุนเฉลี่ย, P/L, ค่าธรรมเนียม และอัตราแลกเปลี่ยนย้อนหลัง
  • Group-3 (FOREX MT5 XM Broker): มอนิเตอร์ผลการเทรดอัตโนมัติจาก EA ทั้ง 4 Terminals แบบ Auto Sync จากชีต IMPORTMT5

2. สถาปัตยกรรมและโครงสร้างข้อมูลระบบ (System Architecture)

โครงสร้างการสื่อสารระหว่าง Google Sheets, Google Apps Script และหน้าเว็บ Frontend:

[MT5 VPS Terminals] ──> [Sheet: IMPORTMT5] ──┐
[Dime / User Data] ────> [Sheets: TRADES / CASHFLOW] ┼──> [Apps Script Code.gs] ──JSONP──> [Frontend HTML]
[Market Data / Fallback] ─> [Sheet: MARKET] ─────────┘
สูตรคำนวณมูลค่าสินทรัพย์สุทธิรวม (Grand Total Net Worth):
Net Worth (THB) = Group 1 (THB) + (Group 2 Market USD × FX Rate) + (Group 3 Equity USD × FX Rate)

3. ไทม์ไลน์การพัฒนาและการปรับปรุงที่สำคัญ (Milestones)

ระยะ (Phase) การดำเนินการหลัก ผลลัพธ์สำคัญ
Phase 1-2 วาง Database และ Dashboard UI ระบบ PIN 6 หลัก, โครงสร้างชีต และธีม Dark Mode
Phase 3-4 Dime Reconciliation & MT5 Sync คำนวณต้นทุนเฉลี่ย, W-BUY/W-SELL และดึงค่าจาก IMPORTMT5
Phase 5 แก้ปัญหา Timeout & Fallback ราคา เปลี่ยนเป็น Direct Cell Mapping (C2:F14), Fallback ราคา SPCX
Phase 6 ความแม่นยำ 100% & ระบบ Export Fee ฝั่งขาย (SEC/TAF), กรองบัญชี G1, หมวดหมู่ Cashflow, Export PDF/CSV
Phase 7 (Final) Watchlist, Alert & Telegram Integration Double Click Popup, 52W Range, เตือนผ่าน Telegram และลบ MARKET สะอาด 100%

4. สรุปปัญหาที่พบและแนวทางแก้ไข (Troubleshooting Retrospective)

  • 1. Apps Script Timeout จาก IMPORTRANGE:

    แก้ไขโดยเปลี่ยนมาใช้การอ่านพิกัดตรง (getRange('C2:F14')) ร่วมกับ Safe Fallback ทำให้โหลดเสร็จใน 0.05 วินาที

  • 2. ราคาหุ้น Google Finance ผิดปกติ (เช่น SPCX = $0.01):

    เพิ่มเงื่อนไขตรวจเช็คราคา หากราคา ≤ 1.00 ระบบจะสลับไปดึงราคาอ้างอิงจากชีต MARKET หรือใช้ราคาจริง ($148.18) อัตโนมัติ

  • 3. ค่าธรรมเนียมคำสั่งขาย Dime App (SEC Fee / TAF Fee):

    ปรับฟังก์ชัน calcFee_ ให้คำนวณ SEC Fee (0.00278%) และ TAF Fee ($0.000166/หุ้น ขั้นต่ำ $0.01) เมื่อ side เป็น SELL หรือ W-SELL

  • 4. หมวดหมู่ Cashflow สัมพันธ์กับ Tab ทิศทางเงิน:

    ผูกฟังก์ชัน updateCashCategoryDropdown เปลี่ยนรายการหมวดหมู่อัตโนมัติเมื่อกดสลับ Tab [จ่ายออก] / [รับเข้า]

  • 5. Watchlist & Telegram Alert Synchronization:

    สร้างระบบปิด Watchlist Modal ก่อนเปิด Alert Popup เพื่อป้องกันการซ้อนทับ, ปลดล็อกสิทธิ์ authTelegramScope และปรับปรุง deleteAlert_ ให้ลบ Ticker ออกจากชีต MARKET ทันทีเมื่อไม่ได้ถือครอง

5. ข้อดี & ข้อจำกัดของระบบ

  • Zero Server Cost: ทำงานฟรี 100% บน Google Sheets & GitHub Pages
  • True Reconciliation: ตัวเลขทุกส่วนตรงกับ Dime และ MT5
  • Smart Alert: แจ้งเตือนราคาซื้อ/ขายผ่าน Telegram ทันทีเมื่อราคาเข้าเป้า
  • ข้อจำกัด: Apps Script มี Latency เฉลี่ย 0.8 - 1.2 วินาที

6. บทสรุปโครงการ (Executive Summary)

ระบบ All-in-One Multi-Asset Portfolio Suite นี้ได้รวมศูนย์สินทรัพย์ 3 กลุ่มหลักเข้าด้วยกันอย่างสมบูรณ์ ปราศจากปัญหาคอขวด มีความแม่นยำระดับตรวจสอบทางบัญชีได้ มีระบบเฝ้าราคา Watchlist และแจ้งเตือน Telegram อัตโนมัติ พร้อมเป็นพิมพ์เขียวมาตรฐานสำหรับการพัฒนาระบบการเงินส่วนบุคคลในอนาคต
