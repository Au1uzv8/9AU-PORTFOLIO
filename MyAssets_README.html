1. แนวคิดและที่มาของระบบ

รวมศูนย์สินทรัพย์ 4 กลุ่มหลัก (All-in-One Net Worth):

  • Group-1: สภาพคล่องเงินบาท — เงินสด, ธนาคาร, เงินสำรองฉุกเฉิน
  • Group-2: หุ้น/ETF สหรัฐ (Dime! Broker) — True Reconciliation, ค่าธรรมเนียม SEC/TAF
  • Group-3: FOREX MT5 XM Broker — 4 Terminals, Firebase Realtime Live
  • Group-4: หุ้นไทย (Dime! Broker) — Commission+Clearing+VAT

5. Price Sync Architecture (v8.4.3)

ราคาหุ้นในระบบมี 2 แหล่ง → แก้ไขให้ตรงกันทุกหน้าด้วย applyLivePrices()

ก่อน v8.4.3 (ปัญหา)
Dashboard → appData.summary (Sheet prices)
Thai/US page → Firebase priceMap (stale)
→ ตัวเลขไม่ตรงกันระหว่างหน้า
หลัง v8.4.3 (แก้แล้ว)
pushToFirebase_() → push REALTIME sheet → Firebase priceMap
ทุกหน้า → applyLivePrices() ใช้ Firebase priceMap ชุดเดียวกัน
→ ตัวเลขตรงกันทุกหน้า ทุก 5 นาที
applyLivePrices(positions, priceMap, isTHB)
├── copy-based: ไม่ mutate appData.summary ตรงๆ
├── US ticker: priceMap["TSLA"] หรือ fallback priceMap["BRK_B"] (dot → underscore)
├── Thai ticker: priceMap["BKK:BDMS"] (colon allowed in Firebase key)
└── Dashboard .once() → .on() (live listener แทน 5-min poll)

6. Alert Engine & Market Hours Guard (BE v9.3)

Telegram Bot จะส่ง alert เฉพาะช่วงเวลาซื้อ-ขายของแต่ละตลาด (isMarketOpen_)

ตลาดเวลา BKK ที่ alert ทำงานGuard ที่
US (NYSE/NASDAQ)จ-ศ 20:00–04:00 BKK (ครอบ EST + EDT)processPos(), cron loop, proximity
Thai (SET)จ-ศ 10:00–17:30 BKKprocessPos(), cron loop, proximity
Alert Types ที่ระบบรองรับ:
├── SL-20% URGENT → แจ้งทุก 15 นาที (ขณะตลาดเปิด)
├── SL-15% WARNING → แจ้งทุก 60 นาที
├── TP Zone PROFIT → แจ้งเมื่อเข้าโซน Target Price
└── 52W Proximity → แจ้งเมื่อราคาใกล้ 52W High/Low ±3%
