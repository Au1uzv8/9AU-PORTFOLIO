5. ปัญหาที่พบและแนวทางแก้ไข

  • Apps Script Timeout (popup ใช้เวลานาน):

    แก้ด้วย Firebase Hybrid — ข้อมูล realtime ดึงจาก Firebase (<300ms) ไม่ต้องรอ Apps Script แล้ว

  • ไฟล์ HTML เดียว 2800+ บรรทัด รวนเมื่อแก้ไข:

    แก้ด้วย Multi-Page — แต่ละ Tab เป็น HTML แยก ~300-660 บรรทัด แก้ไขระบุไฟล์ชัดเจน

  • ราคาหุ้น Google Finance เพี้ยน (SPCX=$0.01):

    ใช้ REALTIME Sheet เป็น source of truth → push ไป Firebase ทุก 5 นาที มี Guard >1.0

  • Token หมดอายุ ต้อง Login ซ้ำทุกหน้า:

    ใช้ localStorage เก็บ token ร่วมกันทุกหน้า Login ครั้งเดียวใช้ได้ทุก Tab (12 ชั่วโมง)

7. ข้อดีของระบบ

  • Zero Server Cost: Google Sheets + Firebase Free Tier + GitHub Pages
  • Realtime: Firebase push <300ms แทน JSONP poll
  • True Reconciliation: ตรงกับ Dime App และ MT5
  • Multi-Page: แก้ไขง่าย ระบุไฟล์ชัดเจน ไม่รวน
  • Telegram Alert: แจ้งเตือนราคาเป้าหมายอัตโนมัติ

8. บทสรุป

ระบบ v8.2 Hybrid Firebase ได้แก้ปัญหา Timeout และไฟล์ขนาดใหญ่ ด้วยการแยก 1 Tab = 1 HTML ไฟล์ และเปลี่ยนข้อมูล Realtime มาดึงจาก Firebase RTDB แทน Apps Script โดยตรง ทำให้ระบบเสถียร แก้ไขง่าย และ Response เร็วขึ้นอย่างมีนัยสำคัญ
