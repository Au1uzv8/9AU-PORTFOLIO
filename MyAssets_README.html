5. ปัญหาที่พบและแนวทางแก้ไข

  • Apps Script Timeout (popup ใช้เวลานาน):

    แก้ด้วย Firebase Hybrid — ข้อมูล realtime ดึงจาก Firebase (<300ms) ไม่ต้องรอ Apps Script แล้ว

  • ไฟล์ HTML เดียว 2800+ บรรทัด รวนเมื่อแก้ไข:

    แก้ด้วย Multi-Page — แต่ละ Tab เป็น HTML แยก ~300-660 บรรทัด แก้ไขระบุไฟล์ชัดเจน

  • ราคาหุ้น Google Finance เพี้ยน (SPCX=$0.01):

    ใช้ REALTIME Sheet เป็น source of truth → push ไป Firebase ทุก 5 นาที มี Guard >1.0

  • Token หมดอายุ ต้อง Login ซ้ำทุกหน้า:

    ใช้ localStorage เก็บ token ร่วมกันทุกหน้า Login ครั้งเดียวใช้ได้ทุก Tab (12 ชั่วโมง)

7. Semi-Auto Telegram Alert Engine (v8.3)

ระบบแจ้งเตือนแบบ Semi-Auto แบ่งเป็น 2 โหมดที่ทำงานแยกกันอย่างชัดเจน:

Watchlist (Semi-Auto / Manual Entry)
  • — ตั้งราคา targetBuyPrice / targetSellPrice ด้วยมือ
  • — หุ้นใดก็ได้ (มีหรือไม่มีในพอร์ต)
  • — เป้าหมาย: หาจุด Entry
  • — Cooldown: 24 ชั่วโมง
Auto SL/TP (เฉพาะ Position ที่ถือครอง)
  • — Auto สร้าง ALERTS row ทุก ticker ที่ shares > 0
  • — อ้างอิงราคาจาก REALTIME sheet (US col L/M, Thai col R/S)
  • — ทำงานทุก 5 นาที ผ่าน checkPriceAlertsCron Trigger
  • — pause ได้ด้วย pauseAutoAlert = TRUE ใน ALERTS sheet
Alert Typeเงื่อนไขCooldownหยุดเมื่อ
