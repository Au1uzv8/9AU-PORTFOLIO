Static Mode
?? Guided Static Mode — ระบบนี้ไม่ต้องใช้ GitHub Token ทำหน้าที่ช่วยวิเคราะห์ไฟล์ แนะนำ path ที่ถูกต้อง เปรียบเทียบเวอร์ชัน และแสดง preview ก่อน Push
การ Push ไฟล์จริงยังคงทำผ่าน GitHub Desktop ตามปกติ ไม่มีการเปลี่ยนแปลง workflow เดิม

1?? วิเคราะห์ไฟล์ใหม่

2?? ขั้นตอนการทำงาน (GitHub Desktop)

  1. วิเคราะห์ไฟล์ทางด้านซ้าย เพื่อดู path ที่ถูกต้อง
  2. เปิดโฟลเดอร์ repo 9AU-PORTFOLIO ในเครื่อง  เข้าโฟลเดอร์ ForexDoc/
  3. สร้างโฟลเดอร์ตาม path ที่แนะนำ (ถ้ายังไม่มี)
  4. วางไฟล์ลงในโฟลเดอร์ที่ถูกต้อง
  5. เปิด GitHub Desktop  เห็นไฟล์ใหม่ใน Changes  Commit  Push origin
  6. กลับมาที่หน้านี้ กดปุ่ม "เพิ่ม Preview" เพื่อดูผลในหน้า Dashboard ทันที

3?? อัปเดต files.json

หลัง Push ไฟล์แล้ว กด Export เพื่อดาวน์โหลด files.json ที่อัปเดตแล้ว  วางที่ ForexDoc/files.json  Commit + Push อีกครั้ง
