1️⃣ วิเคราะห์ไฟล์ใหม่

2️⃣ ขั้นตอนที่ต้องทำ (GitHub Desktop)

  1. วิเคราะห์ไฟล์ทางด้านซ้าย เพื่อดู path ที่ระบบแนะนำ
  2. เปิดโฟลเดอร์ repo 9AU-FOREX-EA ในเครื่อง
  3. สร้างโฟลเดอร์ตาม path ที่แนะนำ (ถ้ายังไม่มี) แล้ววางไฟล์ลงไป
  4. เปิด GitHub Desktop → ตรวจสอบไฟล์ที่เปลี่ยนแปลง → Commit → Push origin
  5. กลับมาที่แท็บนี้ กด "เพิ่มเข้ารายการ" เพื่อดู preview ผลลัพธ์ในหน้า Dashboard
